# Classify Your Agent

Answer these questions to determine your agent's taxonomic classification.

## Step 1: Domain (Autonomy)

**Does your agent learn from past interactions?**

- ❌ No — it runs the same way every time → **Automatia**
- ⚠️ Within a conversation, but forgets between sessions → **Adaptia**
- ✅ Yes — it has persistent memory that improves behavior → **Evolventia**

## Step 2: Kingdom (Architecture)

**How many agents are involved?**

- 1 agent, no delegation → **Monagentia**
- Multiple specialized agents coordinated by one → **Polyagentia**
- Many simple agents with emergent behavior → **Swarmia**

## Step 3: Phylum (Memory)

**How does your agent store information?**

- No persistent storage → **Amnesia**
- Flat log / event history → **Episodia**
- Tiered storage with compression or prioritization → **Hierarchia**
- Learned behaviors encoded directly in instructions → **Genetica**

## Step 4: Class (Evolution Mechanism)

**How does your agent's behavior change over time?**

- Random variations tested against metrics → **Darwinia**
- Failures become rules that persist → **Lamarckia**
- Only changes when a human edits the config → **Lysenkoism**
- Acquires new capabilities from external sources → **Symbiotica**

*Note: Most agents are a mix. Choose the dominant mechanism.*

## Step 5: Order (Mutation Rate)

**How often do your agent's instructions change?**

- Every few minutes (automated optimization loops) → **Tachymutas**
- Daily (automated config tweaks) → **Mesomutas**
- Weekly (scheduled review cycles) → **Bradymutas**
- Monthly or less (manual updates only) → **Glaciomutas**

## Step 6: Family (Selection Pressure)

**Who decides if a change is good?**

- Automated metrics (success rate, cost, speed) → **Autoselectae**
- A human reviews and approves → **Homoselectae**
- Automated for safe changes, human for risky ones → **Hybridselectae**

## Step 7: Genus (Specialization)

**What is your agent's primary role?**

- Research / information gathering → **Investigator**
- Code / building → **Fabricator**
- Content / writing → **Narrator**
- Security / auditing → **Custos**
- Strategy / planning → **Strategus**
- Teaching → **Magister**
- Maintenance / operations → **Curator**
- Orchestrating other agents → **Coordinator**
- General purpose → **Generalis**

## Step 8: Species (Name Your Agent)

Format: `[Genus] [descriptor]`

The descriptor should capture what makes your agent unique:
- Its name: `Coordinator atlas`
- Its focus: `Fabricator fullstack`
- Its style: `Narrator longform`
- Its platform: `Investigator perplexity`

## Your Classification

```
[Domain].[Kingdom].[Phylum].[Class].[Order].[Family].[Genus].[species]
```

**Example:**
```
Evolventia.Polyagentia.Hierarchia.Lamarckia.Bradymutas.Hybridselectae.Coordinator.my-agent-v1
```
