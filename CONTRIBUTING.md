# Contributing to Agent Taxonomy

Thank you for your interest! Agent Taxonomy is a research framework — contributions range from taxonomy refinements to reference implementations.

## Ways to Contribute

### 🧬 Taxonomy
- Propose new taxonomic levels or categories
- Challenge existing classifications with real-world counter-examples
- Submit your agent's species classification

### 📚 References
- Link relevant papers (especially from arxiv)
- Add real-world case studies of agent evolution

### 🔧 Examples
- Submit example GENOME.md files from your own agents
- Write classifiers for specific agent platforms
- Build visualization tools

### 📝 Documentation
- Improve explanations and analogies
- Translate to other languages
- Fix typos and clarify ambiguities

## Process

1. Open an issue describing what you'd like to contribute
2. Fork the repo and create a branch
3. Submit a PR with a clear description
4. Discuss in the PR — we value thoughtful disagreement

## Guidelines

- Keep biological analogies accurate — if the mapping breaks down, say so
- Prefer concrete examples over abstract theory
- Cite sources for claims about AI systems
- No vendor lock-in — framework should work across agent platforms

## Code of Conduct

Be kind, be curious, be rigorous. We're exploring new territory together.
